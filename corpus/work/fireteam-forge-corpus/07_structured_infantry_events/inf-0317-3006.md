## Supported mission essential tasks

## Evaluation coded

## Sustainment interval

## Condition

Given an operations order, table of equipment, a sustainment load, an area of operations, while operating in the full range of environmental conditions during daylight and limited visibility.

## Standard

Appropriate to mission, enemy, terrain and weather, troops and fire support available (METT-T), commander's intent, and unit standard operating procedures (SOP).

## Event Components

1. React to chance contact 2. React to ambushes 3. React to indirect fires 4. React to enemy air 5. React to various danger areas: a. Obstacles b. Minefields 6. React to enemy sniper fire 7. React to contact on departure and re-entry or friendly lines 8. React to contact during link up 9. React to contact in the final firing position (FFP) and hide site 10. React to an improvised explosive device (IED) 11. Move as a unit 12. Move by bounds from cover to cover 13. Submit reports, as required 14. Request support a. Extract b. Quick reaction force c. Casualty evacuation (CASEVAC)
