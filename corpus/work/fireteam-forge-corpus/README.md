# Fireteam Forge Public Marine Corps Source Corpus

This package contains 48 publicly accessible government publications or official public program descriptions, Markdown conversions of the three project documents, and 538 separately structured Infantry T&R event records.

Start with [SOURCE_REGISTRY.md](SOURCE_REGISTRY.md), then read [CORPUS_SCHEMA_AND_AI_USE.md](CORPUS_SCHEMA_AND_AI_USE.md). For JMAP and S.P.E.A.R., use [JMAP_SPEAR_PUBLIC_SOURCE_MAP.md](01_core/JMAP_SPEAR_PUBLIC_SOURCE_MAP.md).

## Important source limitation

NAVMC 3500.44E is the current version named by the thesis and training deck, but no public downloadable copy was available in MCPEL when checked on 16 September 2026. The corpus therefore uses the publicly released NAVMC 3500.44D task set as a development proxy. Do not treat it as current operational authority.

The underlying ONR S.P.E.A.R. technical paper and ONR Lethality Report were cited by official Marine Corps material but were not publicly downloadable. The corpus preserves the strongest official public descriptions and does not invent missing definitions or metrics.
